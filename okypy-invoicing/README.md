# Τιμολόγηση παραχωρήσεων και υπηρεσιών ΟΚΥπΥ

Ένα αρχείο HTML που ανοίγει σε Edge ή Chrome, χωρίς εγκατάσταση και χωρίς σύνδεση στο διαδίκτυο:
**`dist/okypy-timologisi.html`**. Τα αρχεία που ανεβάζετε δεν φεύγουν από τον υπολογιστή σας.

## Τι κάνει

| Καρτέλα | Είσοδος | Αποτέλεσμα |
|---|---|---|
| 1. Φάρμακα (ΦΑ) | Excel «ΕΚΔΟΣΕΙΣ ΟΚΥΠΥ» (εξαγωγή SAP) | Ένα τιμολόγιο ανά καρτέλα και μήνα του Posting Date |
| 2. Αναλώσιμα (ΤΠΑ) | Excel ή PDF που σας στέλνουν (π.χ. 24.1022) | Τιμολόγιο με ποσότητα × τιμή μονάδας |
| 3. Υπηρεσίες (ΤΑ / INV) | PDF τιμολογίου One Point | ΤΑ για Τράπεζα Αίματος, INV για Κέντρο Αίματος |
| 4. Μητρώο και SAP | Τα τιμολόγια που εκδόθηκαν | PDF και Excel για ανέβασμα εσόδων στο SAP |
| 5. Ρυθμίσεις | Κωδικοί πελατών SAP, λογαριασμοί εσόδων, υπογράφων | Αποθηκεύονται στον browser, με εξαγωγή σε JSON |

Τον αριθμό τιμολογίου τον δίνει πάντα ο χρήστης. Το εργαλείο σταματά την έκδοση αν ο αριθμός υπάρχει ήδη
και προειδοποιεί αν η ίδια καρτέλα και ο ίδιος μήνας έχουν ήδη τιμολογηθεί.

## Κανόνες υπολογισμού

- Ποσό ΦΑ = −`Amt.in loc.cur.`. Οι εκδόσεις (261 / 956) βγαίνουν θετικές, οι αντιλογισμοί (262 / 955) αρνητικοί.
- Ένας αντιλογισμός συμψηφίζεται με έκδοση του ίδιου μήνα, ίδιου υλικού και ίδιας παρτίδας. Αν δεν βρεθεί
  αντίστοιχη έκδοση, μένει ως αρνητική γραμμή.
- Μετά την ανάγνωση το εργαλείο δείχνει αν το σύνολο του αρχείου συμφωνεί με το σύνολο των τιμολογίων.
- ΤΠΑ: ποσό γραμμής = ROUND(ποσότητα × τιμή, 2). Σύνολο = άθροισμα των στρογγυλεμένων γραμμών.

## Excel για SAP

Πέντε καρτέλες: `SAP_Upload` (δύο γραμμές ανά τιμολόγιο: χρέωση πελάτη 01, πίστωση εσόδων 50), `Τιμολόγια`,
`Γραμμές`, `Έλεγχος` και `Σημειώσεις`. Τα ποσά είναι ζωντανοί τύποι:
`Γραμμές → Τιμολόγια (SUMIFS) → SAP_Upload`. Η καρτέλα `Έλεγχος` γράφει «ΟΚ» μόνο όταν χρεώσεις = πιστώσεις =
τιμολόγια = γραμμές και κανένας λογαριασμός δεν είναι κενός.

## Αναδημιουργία του αρχείου

```bash
python3 build.py
```

Ο κώδικας είναι στο `src/` και οι βιβλιοθήκες στο `vendor/`: SheetJS 0.18.5, jsPDF 2.5.1,
jsPDF-AutoTable 3.8.2, pdf.js 3.11.174 και η γραμματοσειρά Liberation Sans (συμβατή με Arial, με ελληνικούς χαρακτήρες).
