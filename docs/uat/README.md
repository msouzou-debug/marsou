# UAT του eCapital

## Βιβλίο εργασίας ανά ρόλο (26/11/2026)

`eCapital-UAT-ανά-ρόλο-2026-11-26.xlsx` έχει τα σενάρια δοκιμών αποδοχής ανά ρόλο, για τον διακομιστή του ΟΚΥπΥ με έναν λογαριασμό δοκιμής ανά ρόλο.

- **Οδηγίες**: σκοπός, πώς καταγράφεται ένα αποτέλεσμα, οι τιμές του, οι λογαριασμοί δοκιμής (χωρίς κωδικούς), τα δεδομένα δοκιμής και η σειρά εκτέλεσης των ροών.
- **Σύνοψη**: ανά ρόλο πόσα σενάρια, πόσα πέτυχαν, απέτυχαν, μπλοκαρίστηκαν ή δεν εκτελέστηκαν, ποσοστό ολοκλήρωσης και επιτυχίας, νέα σενάρια. Όλα είναι τύποι πάνω στα φύλλα των ρόλων.
- **Ένα φύλλο ανά ρόλο**, με τη σειρά του πίνακα «Ρόλοι και δικαιώματα»: Προϊστάμενος Τεχνικών Υπηρεσιών, Μηχανικός έργου, Τεχνίτης, Οικονομική Διεύθυνση, Κλινικός εγκριτής, Εγκρίνων τεχνικών και ασφάλειας, Διοίκηση, Ελεγκτής, Διαχειριστής. Κάθε φύλλο έχει την καθημερινή δουλειά του ρόλου (σενάρια «Θετικό») και όσα δεν πρέπει να μπορεί να κάνει (σενάρια «Άρνηση»). Οι αλλαγές των γύρων UAT της 25/11 και της 26/11/2026 έχουν «Ναι» στη στήλη «Νέο».
- **Παραδοχές**: ό,τι δεν ήταν βέβαιο και όπου ο πίνακας ρόλων και μια οθόνη διαφωνούν.

Ο ελεγκτής συμπληρώνει μόνο τις στήλες «Αποτέλεσμα» (λίστα), «Ελεγκτής», «Ημερομηνία» (ηη/μμ/εεεε) και «Παρατηρήσεις».

## Πώς ξαναφτιάχνεται

Τα σενάρια είναι δεδομένα στο `uat_scenarios.py`. Αλλάξτε τα εκεί και τρέξτε:

```bash
/usr/local/bin/python3 docs/uat/build_uat.py
```

Χρειάζεται `openpyxl` (και `pillow` για το λογότυπο, αλλιώς το αρχείο βγαίνει χωρίς αυτό). Το script ελέγχει ότι τα Α/Α είναι συνεχή και μοναδικά ανά φύλλο, ότι κάθε παραπομπή σε άλλο σενάριο (π.χ. `ENG-19`) υπάρχει, και ότι τα κείμενα δεν έχουν «Παρακαλώ», θαυμαστικό, αγγλικό ερωτηματικό ή «Ποινή». Ξαναφτιάχνει το αρχείο από την αρχή, άρα όσα αποτελέσματα έχουν γραφτεί σε παλιό αντίγραφο δεν μεταφέρονται.

Για να δείτε ότι οι τύποι της «Σύνοψης» υπολογίζουν:

```bash
soffice --headless --convert-to xlsx --outdir /tmp/uat-check docs/uat/eCapital-UAT-ανά-ρόλο-2026-11-26.xlsx
```

και διαβάστε το αποτέλεσμα με `openpyxl.load_workbook(..., data_only=True)`.
