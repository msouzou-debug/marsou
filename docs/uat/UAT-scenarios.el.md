# eCapital — Σενάρια δοκιμών αποδοχής (UAT)

Έκδοση 05/10/2026. Για τη δοκιμαστική εγκατάσταση στο `capital.shso.online` με τα δείγματα δεδομένων (41 έργα, 17 συμβάσεις, 8 άδειες, 26 πάγια). Κανένα από τα στοιχεία δεν είναι πραγματικό.

## Πριν ξεκινήσετε

- Ο Διαχειριστής συστήματος σας έχει δώσει όνομα χρήστη και κωδικό, ή σας έχει ορίσει κωδικό σε έναν από τους δοκιμαστικούς λογαριασμούς του πίνακα.
- Χρησιμοποιήστε Chrome ή Edge. Για τα σενάρια κινητού, το κινητό σας ή το παράθυρο του περιηγητή στενεμένο στα 390 px.
- Κάθε σενάριο έχει αναμενόμενο αποτέλεσμα. Σημειώστε «Πέρασε», «Απέτυχε» ή «Με παρατήρηση» και γράψτε δύο γραμμές για ό,τι σας ξένισε. Η βοήθεια κάθε οθόνης ανοίγει με το κουμπί «Βοήθεια» ή το πλήκτρο `?`.

Στήλες κάθε πίνακα: Βήματα, Αναμενόμενο, Αποτέλεσμα (συμπληρώνετε εσείς).

## Α. Σύνδεση και πρόσβαση (όλοι)

| # | Βήματα | Αναμενόμενο | Αποτέλεσμα |
|---|---|---|---|
| Α1 | Ανοίξτε τη σελίδα. Γράψτε το όνομα χρήστη σας και λάθος κωδικό. | Μήνυμα «Το όνομα χρήστη ή ο κωδικός δεν είναι σωστά». Τίποτε άλλο. | |
| Α2 | Γράψτε τον σωστό κωδικό. | Μπαίνετε στο Χαρτοφυλάκιο. Το όνομά σας φαίνεται πάνω δεξιά. | |
| Α3 | Ως `engineer.larnaca`, ανοίξτε τον επιλογέα μονάδας πάνω αριστερά. | Μόνο η Λάρνακα. Ως `admin`, και οι δώδεκα μονάδες. | |
| Α4 | Αλλάξτε γλώσσα από το κουμπί EN/ΕΛ. | Όλη η οθόνη αλλάζει γλώσσα. Τα ποσά μένουν «1.234,56 €», οι ημερομηνίες ηη/μμ/εεεε. | |
| Α5 | Πατήστε `?` σε οποιαδήποτε οθόνη. | Ανοίγει η βοήθεια της οθόνης, στη γλώσσα που έχετε επιλέξει. | |
| Α6 | Πατήστε «Οδηγοί» στο μενού. | Λίστα με δεκαέξι PDF, ένα ανά ρόλο και γλώσσα. Κατεβάστε τον δικό σας. | |
| Α7 | Πατήστε «Αποσύνδεση» και μετά το κουμπί «Πίσω» του περιηγητή. | Επιστρέφετε στη σελίδα σύνδεσης, όχι σε δεδομένα. | |
| Α8 | Ως `admin`, γράψτε πέντε φορές λάθος κωδικό για έναν λογαριασμό δοκιμής, μετά τον σωστό. | Και ο σωστός απορρίπτεται. Μετά από δεκαπέντε λεπτά περνά. | |

## Β. Χαρτοφυλάκιο και έργα (Προϊστάμενος, Μηχανικός, Διοίκηση)

| # | Βήματα | Αναμενόμενο | Αποτέλεσμα |
|---|---|---|---|
| Β1 | Ως `estates.nicosia`, δείτε το Χαρτοφυλάκιο. | Μία γραμμή ανά μονάδα που βλέπετε, με Εγκεκριμένο, Δεσμεύσεις, Δαπάνες, Πρόβλεψη και χρώμα RAG. Όπου δεν υπάρχει πηγή, «—» και όχι 0. | |
| Β2 | Πατήστε τη γραμμή της Λευκωσίας. | Ανοίγει η λίστα έργων φιλτραρισμένη στη Λευκωσία. | |
| Β3 | Στα Έργα, φιλτράρετε ανά φάση «Σε εξέλιξη» και αναζητήστε «χειρουργ». | Η λίστα μικραίνει. Το «Ανακαίνιση χειρουργείων» εμφανίζεται. | |
| Β4 | Ανοίξτε το έργο. Δείτε τις καρτέλες Επισκόπηση, Χρονοδιάγραμμα, Κίνδυνοι και θέματα, Κόστος. | Τα ποσά της Επισκόπησης συμφωνούν με την καρτέλα Κόστος. | |
| Β5 | Πατήστε «Νέο έργο». Αφήστε τον τίτλο κενό και πατήστε Αποθήκευση. | Μήνυμα στο πεδίο, όχι γενικό σφάλμα. | |
| Β6 | Συμπληρώστε τίτλο, κατηγορία, μονάδα, προϋπολογισμό. Αποθηκεύστε. | Το έργο παίρνει κωδικό της μορφής `NGH-2026-0xx` και ανοίγει. | |
| Β7 | Στο Χρονοδιάγραμμα προσθέστε ορόσημο με ημερομηνία πριν από το προηγούμενο. | Το σύστημα το δέχεται ή εμφανίζει προειδοποίηση, αλλά δεν χάνει τα δεδομένα. Σημειώστε τι είδατε. | |
| Β8 | Στους Κινδύνους προσθέστε κίνδυνο με πιθανότητα 4 και επίπτωση 5. | Εμφανίζεται με κόκκινη βαθμολογία στην κορυφή της λίστας. | |
| Β9 | Ως `executive`, προσπαθήστε να αλλάξετε τον τίτλο ενός έργου. | Δεν υπάρχει κουμπί επεξεργασίας, ή η αποθήκευση απορρίπτεται με μήνυμα μόνο ανάγνωσης. | |
| Β10 | Ως `engineer.larnaca`, γράψτε στη γραμμή διεύθυνσης τον σύνδεσμο ενός έργου Λευκωσίας. | Μήνυμα ότι δεν βρέθηκε. Ποτέ τα δεδομένα. | |

## Τι δεν δοκιμάζεται σε αυτή την έκδοση

- Σύνδεση με Active Directory. Εκκρεμεί από το Τμήμα Πληροφορικής.
- Αποστολή συμβάσεων στο eFinance. Ο διακόπτης μένει κλειστός όσο τα δεδομένα είναι δείγματα.
- Εντολές εργασίας, προληπτική συντήρηση, οθόνη αναφορών. Ορόσημα M5 και M6. Οι σελίδες «Συντήρηση» και «Αναφορές» το λένε και δείχνουν τι υπάρχει.
- Αποστολή εγγράφων στο eArchive από τα δείγματα. Τα έγγραφα καταγράφονται και περιμένουν.

## Πώς αναφέρετε ένα εύρημα

Ένα εύρημα ανά γραμμή: αριθμός σεναρίου, λογαριασμός, τι κάνατε, τι περιμένατε, τι είδατε, στιγμιότυπο οθόνης. Στείλτε τα στις Τεχνικές Υπηρεσίες με θέμα «eCapital UAT».
