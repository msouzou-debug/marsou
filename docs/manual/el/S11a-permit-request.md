# Αίτημα διακοπής

Ο οδηγός καταγράφει βήμα προς βήμα ένα νέο αίτημα διακοπής συστήματος: ποια συστήματα και χώροι επηρεάζονται, πότε και για πόσο. Κάθε βήμα αποθηκεύεται αυτόματα, ώστε μια ανανέωση της σελίδας να μη χάνει τίποτα.

## Βήματα

1. Επιλέξτε τα συστήματα που διακόπτονται, το είδος εργασίας, τον τίτλο και την περιγραφή· προαιρετικά συνδέστε ένα έργο ή μία σύμβαση.
2. Επιλέξτε τους χώρους που επηρεάζονται στη μονάδα σας· οι έμμεσα επηρεαζόμενοι χώροι εμφανίζονται αυτόματα και δεν αφαιρούνται.
3. Ορίστε την προγραμματισμένη έναρξη και λήξη· αν η εργασία επηρεάζει πυρασφάλεια ή διαφυγή, σημειώστε το ώστε να ενεργοποιηθούν τα προσωρινά μέτρα ασφάλειας ζωής (ILSM).
4. Ελέγξτε την επισκόπηση και πατήστε «Συνέχεια στην ICRA» για να προχωρήσετε στην εκτίμηση κινδύνου λοιμώξεων.

## Τι μπορεί να πάει λάθος

- **Δεν βλέπετε κάποιον χώρο στη λίστα.** Η λίστα δείχνει μόνο τους χώρους της μονάδας που επιλέξατε στο πρώτο βήμα.
- **Ένας χώρος δεν αφαιρείται.** Είναι έμμεσα επηρεαζόμενος από κάποιο σύστημα που επιλέξατε· η ένδειξη λέει μέσω ποιου συστήματος.
- **Χάσατε τη σύνδεση στη μέση του αιτήματος.** Το αίτημα έχει ήδη αποθηκευτεί ως πρόχειρο· ανοίξτε το ξανά από τη λίστα αδειών για να συνεχίσετε.
