# Σύνδεση

Η οθόνη σύνδεσης σας αναγνωρίζει και ανοίγει το eCapital με τις μονάδες που σας ανήκουν. Στον διακομιστή του ΟΚΥπΥ η αναγνώριση γίνεται με τον λογαριασμό του Active Directory — ζητούνται «Όνομα χρήστη» και «Κωδικός», όπως στο eMAP και στο eFinance. Στο περιβάλλον ανάπτυξης μπαίνετε με έναν από τους οκτώ δοκιμαστικούς λογαριασμούς, γράφοντας μόνο διεύθυνση ηλεκτρονικού ταχυδρομείου.

Η οθόνη δείχνει τη μία ή την άλλη μορφή, ποτέ και τις δύο. Τα βήματα πιο κάτω περιγράφουν τη μορφή του περιβάλλοντος ανάπτυξης· για τη σύνδεση με λογαριασμό ΟΚΥπΥ δείτε το «Σύνδεση και έλεγχος πρόσβασης» (M0-login).

## Βήματα

1. Ανοίξτε οποιαδήποτε σελίδα του eCapital χωρίς να είστε συνδεδεμένοι. Το σύστημα σας φέρνει εδώ και θυμάται τη σελίδα που ζητήσατε.
2. Γράψτε τη διεύθυνση ηλεκτρονικού ταχυδρομείου σας στο πεδίο.
3. Πατήστε «Σύνδεση». Όσο κρατά η σύνδεση, το κουμπί δείχνει «Γίνεται σύνδεση…».
4. Μόλις συνδεθείτε, το σύστημα σας πηγαίνει στη σελίδα που ζητήσατε αρχικά ή στο Χαρτοφυλάκιο έργων.
5. Στο περιβάλλον ανάπτυξης, πατήστε έναν από τους δοκιμαστικούς λογαριασμούς κάτω από το κουμπί για να συμπληρωθεί το πεδίο, και μετά «Σύνδεση».
6. Για να αποσυνδεθείτε, πατήστε «Αποσύνδεση» πάνω δεξιά σε οποιαδήποτε σελίδα.

## Τι μπορεί να πάει λάθος

- **«Η σύνδεση ανάπτυξης δεν είναι ενεργή».** Το API τρέχει χωρίς `DEV_AUTH=1`, οπότε δεν εκδίδει δοκιμαστικά διακριτικά. Ξεκινήστε το με `DEV_AUTH=1` ή συνδεθείτε με τον λογαριασμό ΟΚΥπΥ.
- **«Δεν βρέθηκε λογαριασμός με αυτή τη διεύθυνση».** Ελέγξτε τη διεύθυνση. Αν χρησιμοποιείτε δοκιμαστικό λογαριασμό, φορτώστε τα δοκιμαστικά δεδομένα με `pnpm --filter @ecapital/api seed`.
- **«Ο διακομιστής δεν απάντησε».** Το API δεν ακούει στη θύρα 3001. Ξεκινήστε το με `pnpm --filter @ecapital/api dev` και δοκιμάστε ξανά.
- **Επιστρέφετε στη σύνδεση ενώ είχατε ήδη συνδεθεί.** Το διακριτικό σας έληξε. Ισχύει για οκτώ ώρες. Συνδεθείτε ξανά.
- **Η οθόνη ζητά όνομα χρήστη και κωδικό αντί για διεύθυνση.** Ο διακομιστής είναι ρυθμισμένος για Active Directory. Χρησιμοποιήστε τον λογαριασμό του δικτύου σας· οι δοκιμαστικοί λογαριασμοί δεν ισχύουν εκεί.
- **Βλέπετε λιγότερες μονάδες από όσες περιμένατε.** Βλέπετε μόνο τις μονάδες στις οποίες ανήκετε. Ζητήστε πρόσβαση από τον Διαχειριστή συστήματος.
