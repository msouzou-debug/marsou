# Αξιολόγηση αναδόχων

Η οθόνη δείχνει πόσο τήρησε ο ανάδοχος τους χρόνους της σύμβασης σε μια περίοδο: ανταπόκριση, αποκατάσταση, αναφορές, προληπτική, ώρες εκτός λειτουργίας και τις ποινές που προκύπτουν. Υπολογίζεται κάθε φορά από τις ίδιες τις εντολές, γι' αυτό συμφωνεί πάντα με τη λίστα.

## Βήματα

1. Επιλέξτε τη σύμβαση συντήρησης.
2. Επιλέξτε περίοδο: «Τρέχον τρίμηνο», «Προηγούμενο τρίμηνο», ή δικές σας ημερομηνίες στα «Από» και «Έως». Η σύμβαση πληρώνεται ανά τρίμηνο.
3. Διαβάστε τις κάρτες. Κάθε ποσοστό έχει από κάτω πόσα ήταν εντός χρόνου από πόσα έπρεπε.
4. Δείτε τον πίνακα ανά ζώνη προτεραιότητας, τις ποινές ανά είδος, τη χρήση του ορίου ποινών και τα πάγια με τρεις ή περισσότερες βλάβες.
5. Πατήστε «Εξαγωγή σε Excel». Το αρχείο έχει τους τύπους των ποσοστών και των ποινών, ώστε η Οικονομική Διεύθυνση να ελέγξει το ποσό που κρατά.

## Τι μπορεί να πάει λάθος

- **Βλέπετε «ρήτρες ελλιπείς».** Λείπουν ποσά ποινών από τον κατάλογο συστημάτων. Οι καθυστερήσεις μετρήθηκαν αλλά δεν τιμολογήθηκαν. Ζητήστε από τον Προϊστάμενο Τεχνικών Υπηρεσιών να τα συμπληρώσει στην Προληπτική συντήρηση.
- **Ένα ποσοστό δείχνει «—».** Στην περίοδο δεν υπήρχε τίποτα να μετρηθεί για αυτόν τον χρόνο.
- **Η χρήση του ορίου ποινών λείπει.** Η σύμβαση δεν έχει καταχωρισμένη αξία.
