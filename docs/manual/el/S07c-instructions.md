# Οδηγίες εργοταξίου

Η οθόνη καταγράφει τις οδηγίες προς τον ανάδοχο για μία σύμβαση και δείχνει ποιες έχουν οικονομική επίπτωση. Τη χρησιμοποιούν οι μηχανικοί έργων και οι Τεχνικές Υπηρεσίες για να εκδίδουν οδηγίες και να τις μετατρέπουν σε τροποποίηση σύμβασης όταν κοστίζουν.

## Βήματα

1. Πατήστε «Προσθήκη», γράψτε την οδηγία και σημειώστε αν έχει οικονομική επίπτωση.
2. Στη στήλη «Οικονομική επίπτωση» βλέπετε αμέσως ποιες οδηγίες κοστίζουν.
3. Για μία οδηγία με οικονομική επίπτωση χωρίς τροποποίηση, πατήστε «Δημιουργία τροποποίησης». Ανοίγει προσχέδιο τροποποίησης στην S08, με μηδενική αξία μέχρι να την τιμολογήσει ο μηχανικός.
4. Για μία οδηγία που έχει ήδη τροποποίηση, ο σύνδεσμος στη στήλη «Τροποποίηση» ανοίγει τη λίστα τροποποιήσεων.

## Τι μπορεί να πάει λάθος

- **Δεν βλέπετε «Δημιουργία τροποποίησης».** Είτε η οδηγία δεν έχει οικονομική επίπτωση, είτε έχει ήδη τροποποίηση· δεν δημιουργείτε δεύτερη τροποποίηση από την ίδια οδηγία.
- **Η πορτοκαλί λωρίδα στην κορυφή.** Η σύμβαση έχει οδηγίες με οικονομική επίπτωση που δεν έχουν ακόμη τροποποίηση· δημιουργήστε την όταν είστε έτοιμοι να την τιμολογήσετε.
- **Δεν βλέπετε «Προσθήκη».** Μόνο μηχανικός έργου, προϊστάμενος Τεχνικών Υπηρεσιών και διαχειριστής συστήματος εκδίδουν οδηγίες εργοταξίου.
