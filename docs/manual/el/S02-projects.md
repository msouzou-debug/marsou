# Έργα

Η οθόνη δείχνει όλα τα έργα που βλέπετε, με τον προϋπολογισμό, τις δεσμεύσεις, τις δαπάνες και την κατάσταση RAG του καθενός. Τη χρησιμοποιούν μηχανικοί, Τεχνικές Υπηρεσίες και Οικονομική Διεύθυνση για να βρουν ένα έργο και να ανοίξουν την επισκόπησή του.

## Βήματα

1. Φιλτράρετε με τα κουμπιά «Μονάδα», «Φάση», «Κατηγορία» και «RAG» πάνω από τον πίνακα· κάθε επιλογή ενημερώνει αμέσως τη λίστα και τη διεύθυνση της σελίδας, ώστε να μπορείτε να τη μοιραστείτε ή να την αποθηκεύσετε στους σελιδοδείκτες.
2. Γράψτε στο πεδίο αναζήτησης για να περιορίσετε τη λίστα σε κωδικό ή τίτλο έργου.
3. Πατήστε την επικεφαλίδα μιας στήλης για να ταξινομήσετε με βάση αυτήν· πατώντας ξανά αντιστρέφετε τη σειρά.
4. Πατήστε μια γραμμή, ή επιλέξτε την και πατήστε Enter, για να μεταβείτε στην επισκόπηση του έργου.
5. Αποθηκεύστε τον συνδυασμό φίλτρων που χρησιμοποιείτε συχνά από τις «Αποθηκευμένες προβολές», ή πατήστε «Καθαρισμός όλων» για να αφαιρέσετε όλα τα φίλτρα.

## Τι μπορεί να πάει λάθος

- **«Δεν βρέθηκαν έργα με αυτά τα φίλτρα».** Κανένα έργο δεν ταιριάζει με τον συνδυασμό που επιλέξατε. Πατήστε «Καθαρισμός φίλτρων» για να ξεκινήσετε από την πλήρη λίστα.
- **«Τα δεδομένα δεν φορτώθηκαν».** Το API δεν απάντησε. Πατήστε «Δοκιμάστε ξανά». Αν επιμένει, ενημερώστε τις Τεχνικές Υπηρεσίες.
- **Γράφει ότι είστε εκτός σύνδεσης.** Βλέπετε αποθηκευμένα δεδομένα· η λίστα διαβάζεται κανονικά αλλά δεν ενημερώνεται μέχρι να επανέλθει η σύνδεση.
- **Το κουμπί «Προσθήκη» είναι απενεργοποιημένο.** Ο ρόλος σας δεν δημιουργεί έργα. Ζητήστε από τον Μηχανικό έργου ή τον Προϊστάμενο Τεχνικών Υπηρεσιών της μονάδας να καταχωρίσει το έργο.
- **Δεσμεύσεις ή δαπάνες δείχνουν «—».** Το έργο δεν έχει ακόμη στοιχεία από το SAP· αυτό δεν σημαίνει μηδενικό ποσό, απλώς δεν έχει καταχωριστεί ακόμη.
