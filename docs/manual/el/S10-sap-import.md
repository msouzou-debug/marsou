# Εισαγωγή SAP

Η οθόνη ανεβάζει αρχεία εξαγωγής SAP (ME2N, KSB1, FBL1N) και αντιστοιχίζει τις κινήσεις τους σε έργα και συμβάσεις. Τη χρησιμοποιούν οι Οικονομικές Υπηρεσίες και ο διαχειριστής συστήματος για να ενημερώνουν τις δεσμεύσεις και τις δαπάνες κάθε μήνα.

## Βήματα

1. Ανοίξτε «Κόστος» στην κύρια πλοήγηση και επιλέξτε την καρτέλα «Εισαγωγή SAP».
2. Επιλέξτε το αρχείο, την αναφορά SAP και την περίοδο.
3. Πατήστε «Δοκιμαστική εκτέλεση» για να δείτε πόσες γραμμές αντιστοιχίζονται αυτόματα, χωρίς να αποθηκευτεί τίποτα.
4. Αν το αποτέλεσμα σας ικανοποιεί, πατήστε «Εισαγωγή» για να καταχωριστεί η παρτίδα.
5. Ανοίξτε την παρτίδα από τη λίστα για να δείτε την ουρά αντιστοίχισης των κινήσεων που δεν βρήκαν έργο.
6. Για κάθε κίνηση, δείτε την προτεινόμενη αντιστοίχιση στη δεξιά στήλη και πατήστε Enter για να την αποδεχτείτε, ή πατήστε 1 έως 9 για μία από τις εναλλακτικές.
7. Πατήστε «s» για να παραλείψετε μία κίνηση, ή επιλέξτε πολλές με το πλήκτρο Space και πατήστε Shift+A για μαζική ανάθεση σε ένα έργο.
8. Όταν όλες οι κινήσεις έχουν αντιστοιχιστεί ή παραλειφθεί, πατήστε «Ολοκλήρωση εισαγωγής».

## Τι μπορεί να πάει λάθος

- **Δεν βλέπετε την κάρτα εισαγωγής.** Μόνο οι Οικονομικές Υπηρεσίες και ο διαχειριστής συστήματος εισάγουν αρχεία SAP.
- **Η δοκιμαστική εκτέλεση δείχνει εξαιρέσεις.** Κάποιες γραμμές του αρχείου έχουν πρόβλημα μορφής· διορθώστε το αρχείο και δοκιμάστε ξανά.
- **Η ουρά αντιστοίχισης είναι μόνο για ανάγνωση.** Στο κινητό η ουρά δείχνει τις κινήσεις αλλά δεν αναθέτει· χρησιμοποιήστε υπολογιστή ή tablet.
- **Δεν βλέπετε καμία πρόταση για μια κίνηση.** Χρησιμοποιήστε τη μαζική ανάθεση για να την αναζητήσετε χειροκίνητα.
- **«Τα δεδομένα δεν φορτώθηκαν».** Το API δεν απάντησε. Πατήστε «Δοκιμάστε ξανά».
