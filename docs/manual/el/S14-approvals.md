# Εγκρίσεις

Η οθόνη συγκεντρώνει όλες τις εκκρεμείς εγκρίσεις σας, ομαδοποιημένες κατά είδος, με τα βασικά στοιχεία για να αποφασίσετε γρήγορα. Ανοίγει μία εγγραφή τη φορά, χωρίς να χρειάζεται να δείτε ολόκληρο τον φάκελο.

## Βήματα

1. Δείτε τη λίστα ομαδοποιημένη σε Διακοπές, Τροποποιήσεις, Πιστοποιήσεις και Άλλα, με τις πιο πρόσφατες πρώτα.
2. Ανοίξτε μία γραμμή για να δείτε τα τρία βασικά στοιχεία της.
3. Πατήστε «Έγκριση» ή «Επιστροφή με σχόλια»· η επιστροφή απαιτεί σχόλιο.
4. Χρησιμοποιήστε τα πλήκτρα ↑/↓ για μετακίνηση, a για έγκριση, r για επιστροφή, f για το επόμενο και x για κλείσιμο· το πλήκτρο «?» δείχνει όλες τις συντομεύσεις.

## Τι μπορεί να πάει λάθος

- **Δεν βλέπετε κουμπιά έγκρισης σε μια εγγραφή.** Κάποια είδη ανοίγουν μόνο τον πλήρη φάκελο με «Άνοιγμα»· η απόφαση λαμβάνεται εκεί.
- **Πατήσατε «Επιστροφή με σχόλια» χωρίς σχόλιο.** Το κουμπί ενεργοποιείται μόνο αφού γράψετε το σχόλιο.
- **Ήρθατε από ειδοποίηση στο κινητό.** Η εγγραφή ανοίγει κατευθείαν· χρειάζονται μόνο δύο πατήματα για έγκριση.
