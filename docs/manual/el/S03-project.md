# Επισκόπηση έργου

Η οθόνη δείχνει τα στοιχεία ενός έργου: φάση, χρηματοδότηση, ημερομηνίες, κόστος, κατάσταση RAG, ορόσημα, κινδύνους και θέματα. Τη χρησιμοποιούν μηχανικοί, Τεχνικές Υπηρεσίες και Οικονομική Διεύθυνση για να δουν την πλήρη εικόνα ενός έργου σε μία σελίδα.

## Βήματα

1. Ανοίξτε ένα έργο από τη λίστα «Έργα» για να φτάσετε εδώ.
2. Διαβάστε τα στοιχεία στην αριστερή στήλη: φάση, κατηγορία, χρηματοδότηση, ημερομηνίες και τη σημείωση του έργου, αν υπάρχει.
3. Δείτε το ιστορικό ενεργειών κάτω από τα στοιχεία, με την πιο πρόσφατη καταχώριση πρώτη.
4. Στη δεξιά στήλη, δείτε τη γραμμή κόστους, την κατάσταση RAG με την αιτιολογία της, και τις κάρτες «Ορόσημα», «Κίνδυνοι» και «Θέματα».
5. Οι καρτέλες «Κόστος», «Χρονοδιάγραμμα» και «Κίνδυνοι και θέματα» έρχονται σε επόμενη οθόνη· προς το παρόν είναι απενεργοποιημένες.

## Τι μπορεί να πάει λάθος

- **«Δεν έχετε πρόσβαση σε αυτή τη σελίδα».** Το έργο δεν είναι δικό σας ή δεν υπάρχει· η οθόνη δεν ξεχωρίζει τις δύο περιπτώσεις. Ζητήστε πρόσβαση από τον Διαχειριστή συστήματος.
- **«Τα δεδομένα δεν φορτώθηκαν».** Το API δεν απάντησε. Πατήστε «Δοκιμάστε ξανά». Αν επιμένει, ενημερώστε τις Τεχνικές Υπηρεσίες.
- **Γράφει ότι είστε εκτός σύνδεσης.** Βλέπετε αποθηκευμένα δεδομένα· η σελίδα διαβάζεται κανονικά αλλά δεν ενημερώνεται μέχρι να επανέλθει η σύνδεση.
- **Δεσμεύσεις ή δαπάνες δείχνουν «—» στη γραμμή κόστους.** Το έργο δεν έχει ακόμη στοιχεία από το SAP· η γραμμή δείχνει μόνο τον εγκεκριμένο προϋπολογισμό μέχρι να έρθουν.
- **Ένα ορόσημο είναι κόκκινο και γράφει «Εκπρόθεσμο».** Η προβλεπόμενη ημερομηνία πέρασε χωρίς να καταχωριστεί πραγματική ολοκλήρωση.
