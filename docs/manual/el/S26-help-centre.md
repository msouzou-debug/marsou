# Οδηγός χρήσης

Η σελίδα αυτή δίνει πρόσβαση στους δεκαέξι εκτυπώσιμους οδηγούς χρήσης του eCapital, έναν για κάθε ρόλο και γλώσσα. Κατεβάστε αυτόν που ταιριάζει στον ρόλο σας για εκτύπωση ή για την εκπαίδευση νέου προσωπικού.

## Βήματα

1. Βρείτε στον πίνακα τη γραμμή με τον ρόλο και τη γλώσσα που θέλετε.
2. Δείτε το μέγεθος του αρχείου και την ημερομηνία της τελευταίας ενημέρωσης πάνω στην ίδια γραμμή.
3. Πατήστε «Λήψη». Το PDF ανοίγει σε νέα καρτέλα, ώστε να μη χάσετε τη σελίδα στην οποία βρισκόσασταν.
4. Στο εξώφυλλο κάθε οδηγού βλέπετε τον ρόλο, την έκδοση και την ημερομηνία δημιουργίας του — αυτά σας λένε αν κρατάτε την τελευταία έκδοση.

## Τι μπορεί να πάει λάθος

- **Ο πίνακας είναι κενός.** Οι οδηγοί δημιουργούνται σε κάθε έκδοση του eCapital και δεν έχουν δημιουργηθεί ακόμη για αυτή την εγκατάσταση. Ζητήστε από τον διαχειριστή συστήματος να επιβεβαιώσει πότε έγινε η τελευταία έκδοση.
- **Το PDF δεν ανοίγει σε νέα καρτέλα.** Ελέγξτε αν ο περιηγητής σας μπλοκάρει αναδυόμενα παράθυρα και επιτρέψτε τα για τη διεύθυνση του eCapital.
- **Θέλετε να αναζητήσετε μέσα σε όλο το εγχειρίδιο, όχι μόνο στη λίστα των οδηγών.** Αυτή η δυνατότητα δεν έχει προστεθεί ακόμη σε αυτή τη σελίδα· προς το παρόν, χρησιμοποιήστε την αναζήτηση μέσα στο πλαϊνό παράθυρο βοήθειας της κάθε οθόνης, που ψάχνει στην ενότητα εκείνης της οθόνης.
