# Χρονοδιάγραμμα

Η οθόνη δείχνει τα ορόσημα ενός έργου: τη βάση, την πρόβλεψη και την πραγματοποίησή τους, και μία γραμμή χρόνου με τα τρία μαζί. Τη χρησιμοποιούν μηχανικοί και Τεχνικές Υπηρεσίες για να παρακολουθούν πόσο απέχει το έργο από το αρχικό του πλάνο.

## Βήματα

1. Ανοίξτε την καρτέλα «Χρονοδιάγραμμα» από τη σελίδα του έργου, ή πατήστε «Όλα τα ορόσημα» στην κάρτα «Ορόσημα».
2. Διαβάστε τον πίνακα: κάθε γραμμή δείχνει τη βάση, την πρόβλεψη, την πραγματοποίηση, την απόκλιση σε ημέρες και την κατάσταση του ορόσημου.
3. Για να αλλάξετε μία πρόβλεψη ή μία πραγματοποίηση, κάντε διπλό κλικ στο αντίστοιχο κελί, πληκτρολογήστε τη νέα ημερομηνία (ΕΕΕΕ-ΜΜ-ΗΗ) και πατήστε Enter. Το Esc ακυρώνει την αλλαγή.
4. Δείτε τη γραμμή χρόνου κάτω από τον πίνακα για μία οπτική σύγκριση όλων των ορόσημων μαζί με τη σημερινή ημερομηνία.
5. Πατήστε «Προσθήκη» για να καταχωρίσετε ένα νέο ορόσημο: τίτλο, ημερομηνία βάσης και αν πρόκειται για πύλη φάσης.

## Τι μπορεί να πάει λάθος

- **«Δεν έχετε πρόσβαση σε αυτή τη σελίδα».** Το έργο δεν είναι δικό σας ή δεν υπάρχει· η οθόνη δεν ξεχωρίζει τις δύο περιπτώσεις. Ζητήστε πρόσβαση από τον Διαχειριστή συστήματος.
- **«Τα δεδομένα δεν φορτώθηκαν».** Το API δεν απάντησε. Πατήστε «Δοκιμάστε ξανά».
- **Η ημερομηνία βάσης δεν αλλάζει.** Δεν αλλάζει ποτέ μετά τη δημιουργία του ορόσημου· αν άλλαξε το πλάνο, καταχωρίστε νέο ορόσημο αντί να διορθώσετε το παλιό.
- **Η απόκλιση είναι κόκκινη.** Η πρόβλεψη έχει ξεπεράσει τη βάση· δεν είναι κόκκινη όταν η πρόβλεψη είναι νωρίτερα από τη βάση.
- **Η φάση του έργου δεν προχωράει.** Μία πύλη της τρέχουσας φάσης δεν έχει καταχωρισμένη πραγματική ημερομηνία· καταχωρίστε την εδώ για να ξεμπλοκάρει.
