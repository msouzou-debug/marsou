# Αιτήματα διευκρίνισης

Η οθόνη καταγράφει τις ερωτήσεις προς τον φορέα για μία σύμβαση και τις προθεσμίες τους. Τη χρησιμοποιούν οι μηχανικοί έργων και οι Τεχνικές Υπηρεσίες για να υποβάλλουν ερωτήσεις, να καταχωρίζουν την απάντηση και να τις κλείνουν.

## Βήματα

1. Πατήστε «Προσθήκη» και γράψτε την ερώτηση· η προθεσμία είναι 7 ημέρες, εκτός αν ορίσετε άλλη.
2. Παρακολουθήστε την προθεσμία από τη στήλη «Προθεσμία»: πράσινο, πορτοκαλί, κόκκινο ή εκπρόθεσμο.
3. Ανοίξτε μία γραμμή και καταχωρίστε την απάντηση όταν τη λάβετε από τον φορέα.
4. Μόλις απαντηθεί, πατήστε «Ολοκλήρωση» για να την κλείσετε.

## Τι μπορεί να πάει λάθος

- **Η προθεσμία έγινε κόκκινη ή εκπρόθεσμη.** Αυτό δεν εμποδίζει τίποτα· καταχωρίστε την απάντηση και το ρολόι σταματά εκεί.
- **Δεν βλέπετε «Προσθήκη» ή τη φόρμα απάντησης.** Μόνο μηχανικός έργου, προϊστάμενος Τεχνικών Υπηρεσιών και διαχειριστής συστήματος καταγράφουν αιτήματα διευκρίνισης· οι υπόλοιποι ρόλοι τα βλέπουν μόνο.
- **«Κλείνετε ένα αίτημα διευκρίνισης αφού απαντηθεί».** Καταχωρίστε πρώτα την απάντηση και μετά πατήστε «Ολοκλήρωση».
