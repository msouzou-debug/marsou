# Disruption calendar

The calendar shows every approved shutdown across the whole network, together with theatre and ICU disruption hours by unit and month. It also flags clashes between permits.

## Steps

1. Read the disruption hours table for the current year, above the calendar.
2. Move between months with the arrows above the day grid.
3. Filter by unit, area type or system to focus on the permits you care about.
4. Open a permit from the calendar to see its full record.

## What can go wrong

- **A permit carries a warning icon.** It clashes in time or area with another permit; the tooltip names which one. The clash does not block either permit.
- **You see no permits in a month.** Check whether a unit, area type or system filter is narrowing the results.
- **The hours table shows zeros.** No shutdown has been recorded yet for that unit and month.
