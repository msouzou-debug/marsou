# Reports

The reports and exports screen is built in milestone M6. Until then, this page is the index of the figures the system already produces, each linked to the screen that produces it.

## Steps

1. Open «Αναφορές» from the menu.
2. Find what you need under «Τι υπάρχει σήμερα»: portfolio per unit, the project list with its Excel export, accruals, the replacement forecast, the disruption calendar, contracts.
3. Press the link. The export, where there is one, is the button on that screen.

## What can go wrong

- **You want a report that is not on the list.** Write it down and send it to Technical Services. Milestone M6 is built from those requests.
