# Shutdown request

This wizard records a new system shutdown request step by step: which systems and areas are affected, when, and for how long. Every step saves itself automatically, so refreshing the page never loses anything.

## Steps

1. Choose the systems being shut down, the kind of work, the title and the description. Optionally link a project or a contract.
2. Choose the areas affected in your unit. Indirectly affected areas appear on their own and cannot be removed.
3. Set the planned start and end. If the work affects fire safety or escape routes, flag it so interim life safety measures (ILSM) become mandatory.
4. Check the overview and press "Continue to ICRA" to move on to the infection control risk assessment.

## What can go wrong

- **An area is missing from the list.** The list only shows the areas of the unit you picked in step 1.
- **An area will not come off the list.** It is indirectly affected by a system you chose; the label names which system.
- **You lost connection halfway through the request.** The request is already saved as a draft. Open it again from the permits list to carry on.
