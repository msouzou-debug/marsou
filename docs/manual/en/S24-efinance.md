# eFinance

This tab lets you read from eFinance now, instead of waiting for the automatic sync. Only the system administrator has it.

## Steps

1. Open «Administration», then the «eFinance» tab.
2. Press «Sync now» to read eFinance's invoices and requisitions and refresh the contracts' figures.
3. Press «Master data» to refresh the units and the vendor list the contractor form searches.
4. Read the result under the buttons: how many invoices, requisitions and contracts were read, or how many units and vendors were updated.

The system does all of this without you: invoices and requisitions are read every fifteen minutes and master data once a day. The system keeps no run history, so the page shows only the last run you made from here.

## What can go wrong

- **It says «eFinance is not configured in this environment».** This server has no eFinance link set up and nothing was read. Set the link up and try again.
- **It says «Read error» with some text.** eFinance did not answer or refused the read. Try again shortly; the automatic sync will try again by itself.
- **You do not see the «eFinance» tab.** Only the system administrator has access.
