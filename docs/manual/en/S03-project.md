# Project overview

This screen shows one project's facts: phase, funding, dates, cost, RAG status, milestones, risks and issues. Engineers, estates staff and finance use it to see a project's full picture on one page.

## Steps

1. Open a project from the "Projects" list to get here.
2. Read the facts in the left column: phase, category, funding, dates and the project's note, if it has one.
3. Check the activity log below the facts, with the most recent entry first.
4. In the right column, check the cost bar, the RAG status with its reason, and the "Milestones", "Risks" and "Issues" cards. Each card has a link ("All milestones", "All risks", "All issues") to its full register.
5. The "Schedule" and "Risks and issues" tabs open the full milestone or risk-and-issue register. The "Cost" tab comes in a later screen, so it stays disabled for now.

## What can go wrong

- **"You do not have access to this page".** The project is not yours, or it does not exist — this screen does not tell the two apart. Ask the system administrator for access.
- **"The data did not load".** The API did not answer. Press "Try again". If it keeps failing, tell estates.
- **It says you are offline.** You are looking at saved data. The page still reads normally, but it will not update until the connection is back.
- **Commitments or spend show "—" on the cost bar.** The project has no SAP data yet, so the bar shows only the approved budget until it arrives.
- **A milestone is red and says "Overdue".** Its forecast date has passed with no actual completion date recorded.
