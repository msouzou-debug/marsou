# User guide

This page gives you eCapital's sixteen printable user guides, one for each role and language. Download the one that matches your role, to print or to train new staff with.

## Steps

1. Find the row for the role and language you want in the table.
2. Check the file size and the date of the last update on the same row.
3. Click "Download". The PDF opens in a new tab, so you keep the page you were on.
4. Every guide's cover page shows the role, the version and the date it was built — that tells you whether you are holding the latest one.

## What can go wrong

- **The table is empty.** The guides are generated with every eCapital release and have not been generated yet for this installation. Ask the system administrator to confirm when the last release ran.
- **The PDF does not open in a new tab.** Check whether your browser is blocking pop-ups and allow them for the eCapital address.
- **You want to search the whole manual, not just the guide list.** That is not built into this page yet — for now, use the search box inside each screen's help drawer, which searches that screen's own section.
