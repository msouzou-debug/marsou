# Site instructions

This screen records the instructions given to the contractor on a contract and shows which ones carry a cost. Project engineers and estates staff use it to issue an instruction and turn it into a contract variation once it costs something.

## Steps

1. Press "Add", write the instruction and mark whether it has a cost impact.
2. The "Cost impact" column shows at a glance which instructions cost something.
3. For a cost-impact instruction with no variation yet, press "Create variation". This opens a draft variation on S08, priced at zero until the engineer works out the cost.
4. For an instruction that already has a variation, the link in the "Variation" column opens the variations list.

## What can go wrong

- **You do not see "Create variation".** Either the instruction has no cost impact, or it already has a variation — you cannot create a second variation from the same instruction.
- **The amber strip at the top.** The contract has cost-impact instructions with no variation yet. Create one once you are ready to price it.
- **You do not see "Add".** Only a project engineer, the head of estates and the administrator issue site instructions.
