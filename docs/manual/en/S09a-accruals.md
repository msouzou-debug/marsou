# Accruals

The screen shows accruals by project and contract: certified amounts not yet invoiced, for a chosen year. Finance and management use it for the year-end close.

## Steps

1. Open «Cost» in the main navigation and choose the «Accruals» tab.
2. Pick the year from the dropdown.
3. Read the table by project and contract: certified net, invoiced and accrual, with the total at the bottom.
4. Click «Export to Excel» to download the file with the same figures the screen shows.

## What can go wrong

- **You cannot see the screen at all.** It is visible to Finance, the administrator, the head of estates and the two read-only roles.
- **The table is empty.** There are no certified amounts still unbilled for the selected year.
- **"Data did not load".** The API did not respond. Click "Try again".
