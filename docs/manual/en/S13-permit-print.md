# Permit to work (print)

This page shows the work permit as an A4 sheet, ready to print and post at the work site. It shows the class, the controls, the dates, the approvals and a QR code back to the electronic record.

## Steps

1. Open the print view from the permit's own record, with the "Print" button.
2. Check the on-screen preview before printing.
3. Press the page's own "Print" button to print the A4 sheet.
4. Post the printed sheet at the work site, where anyone passing can see it.

## What can go wrong

- **The permit is not approved yet.** The sheet shows whatever facts exist, but the approvals list stays incomplete until they are done.
- **The QR code does not scan cleanly.** Print at full resolution, without shrinking the page.
- **You need the permit in the other language.** Switch the language from the top bar before opening the print view.
