# Asset register

This screen lists every recorded asset in the unit, with its SAP asset class, criticality, condition, warranty and planned replacement year. It is one register for every SAP asset class, from buildings and medical equipment to vehicles and software. It also opens each asset's own record and prints QR labels.

## Steps

1. Filter the table by unit, asset class, SAP asset class, criticality, condition or status to find the asset you need. The "SAP class" column shows the class code and name, for example "111042 — Air-conditioning", and goes into the Excel export.
2. Press the "Priority" column to sort assets by criticality and condition, most urgent first.
3. Select one or more assets with the row checkboxes and press "Print labels" to open their label sheet.
4. Press "Add" to record a new asset, or open a row to see the asset's full record.

## What can go wrong

- **You do not see "Add".** Your role cannot record a new asset; ask the unit's head of estates.
- **"Print labels" stays disabled.** Select at least one asset with its row checkbox.
- **An asset has no SAP class.** Pick "No SAP class" in the filter to find the ones without, and set it with the asset's "Edit". Assets of the class "Other" get no SAP class automatically.
- **You cannot find an asset by search.** Search checks the tag, name and serial number; try part of the tag instead of the whole thing.
