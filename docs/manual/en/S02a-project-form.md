# New project and editing a project

This screen opens a new project or changes an existing one's core details: title, category, funding, budget and schedule. Engineers and estates staff use it to register a project or correct one already in the register.

## Steps

1. From the "Projects" list, press "Add" to open a new project, or "Edit" from a project's overview to change its details.
2. Choose the unit, if you can see more than one — the field is hidden when you only see one, and it cannot change once the project exists.
3. Fill in the Greek title. The English title is optional.
4. Choose a category and a funding source, and enter the approved budget.
5. Enter the planned start and finish, the budget years, the WBS code and the tender reference, where they apply.
6. Press "Save". The screen takes you to the project's overview.

## What can go wrong

- **"Fill in this field."** The title or the budget is missing. Fill it in and press "Save" again.
- **The finish date is refused.** It falls before the start date. Fix one of the two dates.
- **The budget field is refused because only finance may change it after approval.** The project is in the Approved phase or later; ask finance to make the change.
- **The phase will not advance because a gate milestone has no actual date.** Record the milestone's actual date on the "Milestones" card first, then try the phase change again.
- **"You do not have access to this page."** Your role does not allow creating or editing projects. Ask the system administrator for access.
