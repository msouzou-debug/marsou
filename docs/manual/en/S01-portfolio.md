# Portfolio

This screen shows every SHSO project on one page: what is approved, what is committed, what has been spent and where the final cost is expected to land. It is used by the head of estates, finance and management.

## Steps

1. Read the four figures at the top. Under each one you see the percentage of the year that has passed, so you compare spend against time and not only against the budget.
2. In the unit table, click a row to see that unit's projects.
3. Turn on "Group by directorate" for subtotals per directorate.
4. In the "Needs attention" list, click an item to go straight to the project.
5. Click "Export to Excel" at the top right of the table to get the same figures with live formulas.

## What can go wrong

- **The figures do not match SAP.** Spend is updated by the latest SAP file import. Check the date of the last import on the Administration page.
- **A unit is missing.** You only see the units you have access to. Ask the system administrator for access.
- **The "Needs attention" list is empty.** That is good news. The screen says so in words; it never shows an empty box.
