# Schedule

This screen shows a project's milestones: their baseline, forecast and actual dates, and a timeline with all three together. Engineers and estates staff use it to track how far the project has drifted from its original plan.

## Steps

1. Open the "Schedule" tab from the project page, or press "All milestones" on the "Milestones" card.
2. Read the table: each row shows the baseline, the forecast, the actual date, the deviation in days, and the milestone's status.
3. To change a forecast or an actual date, double-click the cell, type the new date (YYYY-MM-DD) and press Enter. Esc cancels the change.
4. Check the timeline below the table for a visual comparison of every milestone against today's date.
5. Press "Add" to record a new milestone: a title, a baseline date, and whether it is a phase gate.

## What can go wrong

- **"You do not have access to this page".** The project is not yours, or it does not exist — this screen does not tell the two apart. Ask the system administrator for access.
- **"The data did not load".** The API did not answer. Press "Try again".
- **The baseline date will not change.** It never changes once the milestone exists — if the plan changed, add a new milestone instead of correcting the old one.
- **The deviation is red.** The forecast has slipped past the baseline; it is not red when the forecast is earlier than the baseline.
- **The project's phase will not advance.** A gate in the current phase has no actual date recorded yet — record it here to unblock the move.
