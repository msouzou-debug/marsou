# RFIs

This screen records the questions raised with the contractor on a contract and their deadlines. Project engineers and estates staff use it to raise a question, record the answer and close it.

## Steps

1. Press "Add" and write the question. The deadline is 7 days unless you set a different one.
2. Watch the deadline in the "Due" column: green, amber, red or overdue.
3. Open a row and record the answer once the contractor gives it.
4. Once it is answered, press "Complete" to close it.

## What can go wrong

- **The deadline turned red or overdue.** This does not block anything — answer it and the clock stops there.
- **You do not see "Add" or the answer form.** Only a project engineer, the head of estates and the administrator record RFIs; other roles can only read them.
- **"You close an RFI once it has been answered."** Record the answer first, then press "Complete".
