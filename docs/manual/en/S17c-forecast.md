# Replacement forecast

This screen shows the estimated cost of replacing assets, by unit, year and SAP asset class, based on each asset's own replacement year and cost estimate.

## Steps

1. Set the year range you want with the "From year" and "To year" fields.
2. Filter by unit if you want to see just one unit.
3. Read the estimated-cost-per-year chart and the table of assets, cost and critical assets by unit, year and SAP asset class. Assets with no SAP class are a row of their own, last in the year.
4. Press "Export to Excel" to download the table as shown, SAP asset class included.

## What can go wrong

- **You do not see this screen.** The replacement forecast is only available to the head of estates, finance, executive readers and the administrator.
- **The table is empty.** No asset has a planned replacement inside the year range you picked; widen the range.
- **You see a "No SAP class" row.** Some assets have no SAP class. Find them in the asset register with the "No SAP class" filter and set it with each asset's "Edit".
