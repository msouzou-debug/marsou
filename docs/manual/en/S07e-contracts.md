# Contracts

This screen lists every contract in your units, with each contract's reference, its number, the contractor and its current value. Use it when you are holding a contract reference — off an eFinance invoice, say — and want the contract it belongs to.

## Steps

1. Open the Contracts page. You see the contracts in your own units and nothing else.
2. Type the contract reference (`CAP-2026-0031`), the contract number or the contractor's name into the search box and press Search.
3. Press the contractor's name on a row to open the contract.
4. If you arrived here from a link that carried a reference, the page takes you straight to the contract with no further step.

A reference like `CAP-2026-0031` is given by the system when the contract is recorded and never changes. The contract number is the number on the tender papers and you type it yourself; the two are not the same thing.

## What can go wrong

- **"No contract carries the reference …".** Check the reference. One starting `CON-` belongs to eMAP, not here. One starting `CAP-` is either in a unit you have no access to or does not exist; the screen does not tell the two apart.
- **The list is empty.** There are no contracts in your units. Contracts are recorded from the project page, after the award.
- **"The data did not load".** The API did not answer. Press Try again.
