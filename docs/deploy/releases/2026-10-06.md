## What this release brings

- `AUTH_MODE=local` (ADR-0030): sign-in with a username and a password
  eCapital holds, set by the administrator in Διαχείριση › Χρήστες or
  with `sudo ecapital-set-password <name> [--create-admin]`. Switched on
  the same day in `api.env` and `web.env`; the first local account is
  `admin`. The directory stays unreachable (runbook §1), so this is the
  bridge until IT answers; the switch back is runbook §5.0.
- Public hostname is `ecapital.shso.online` (owner decision 05/10/2026):
  nginx `server_name`, `NEXT_PUBLIC_APP_ORIGIN` and `CORS_ORIGINS` changed
  on the server by `sed`, nginx tested before reload. The cloudflared
  request now names the record that already exists on the Cloudflare side.
- «Συντήρηση» and «Αναφορές» land on a page instead of a 404; «Οδηγοί»
  in the nav; twenty PDFs in the help centre, the general guide and the
  UAT scenarios first.
- Unit switcher is a filter with «ΟΚΥπΥ — όλες οι μονάδες» first.
- Greek review of every screen string, API message and manual page
  (commits e7ecdef, 5da2b02).
