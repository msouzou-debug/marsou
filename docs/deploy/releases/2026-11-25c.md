## What this release brings

- **«Έναρξη εργασιών»**: the API always allowed the administrator; the
  button was greyed outside the permit's planned window with the reason only
  in a tooltip. The reason is now written under the button with the window's
  dates, and the button turns on by itself when the window opens. An approved
  permit not yet started reads «Εγκρίθηκε, οι εργασίες δεν άρχισαν» instead
  of «Σε ισχύ».
- **«Request to … failed with 401»**: an expired sign-in (8 hours) now says
  «Η σύνδεσή σας έληξε. Συνδεθείτε ξανά.» and offers to sign in and return to
  the same page, or in a new tab so typed text is kept. A server restart
  during a release no longer signs people out. No English fallback messages.
- **RFI by e-mail**: «Αποστολή με e-mail» opens Outlook with recipient,
  subject and body filled in; then one click records today as sent on.
  eCapital does not send mail itself (no relay on the network yet).
- **Side sheets** (RFI, site instruction, defect, variation, risk, issue,
  user, contractor, invoice lines) sit above the top bar and table, with
  «Πίσω στη λίστα», Escape and a click outside to close.
- **Contractor**: picking the SAP vendor fills e-mail and telephone from
  eFinance into empty fields.
