# ΟΚΥπΥ — Πίνακας Δεικτών Νοσοκομείου (v2)

Πίνακας δεικτών νοσοκομείου που τρέχει **εξ ολοκλήρου τοπικά**: ένα αυτόνομο αρχείο
HTML, χωρίς διακομιστή και χωρίς δίκτυο. Τα αρχεία «Πληρωμένες Απαιτήσεις OS»
περιέχουν ονόματα ασθενών — **κανένα δεδομένο δεν φεύγει από τον υπολογιστή**.

Περιεχόμενο: το **Milestone 1** του build brief — διάσπαση του μονοκόμματου v1.4
σε modules, build που παράγει ξανά ένα αρχείο, και δοκιμές που αποδεικνύουν ότι
η συμπεριφορά δεν άλλαξε — και η ενότητα **«Ανά κλινική»**, που δίνει στους
διευθυντές κλινικών την εικόνα της δικής τους κλινικής.

## Γρήγορη εκκίνηση

```bash
npm install
npm run build     # → dist/ΟΚΥπΥ_Πίνακας_Δεικτών_Νοσοκομείου.html
npm test          # build + fixtures + unit + golden (Playwright)
```

Το `dist/…html` ανοίγει με διπλό κλικ σε Chrome/Edge, και εκτός δικτύου.

## Δομή

```
src/
  index.html            σκελετός σελίδας με placeholders (<!--APP_BUNDLE--> κ.λπ.)
  styles.css            μάρκα ΟΚΥπΥ (πράσινο #8BC53F, μπλε #069FEC / #1B75BB)
  assets/               τα λογότυπα του v1.4 σε base64
  vendor/               SheetJS 0.18.5 (Apache-2.0), ενσωματωμένη για offline χρήση
  util.js               U — μορφοποίηση, ελληνικοί μήνες
  workbook.js           grid / findSheet / parseBlocks / parseAnnualTable / parseDMY
  domain.js             σταθερές και κανόνες πεδίου (KPI_DEFS, HOSP_KEYS, TAG2HOSP,
                        OP_EXCLUDE, OS_LAB, clinicKey)
  state.js              το κοινό, προσθετικό state
  parsers/              stats · is · allae · os · classify
  model/                hio · os · clinic · blocks · story
  render/               dashboard · clinics · hio · allae · os · charts · dom
  intake.js             υποδοχή αρχείων (drag-drop / επιλογή)
  main.js               σύνδεση και window.OKYPY
build.mjs               esbuild → ένα αυτόνομο HTML
reference/              το v1.4 ως σημείο σύγκρισης
test/                   unit · build · golden
```

Το δημόσιο API μένει ίδιο με το v1.4:
`window.OKYPY = { state, handleFiles, parseStats, parseIS, computeHIO, U }`.

### Γιατί ένα αρχείο

Οι υπολογιστές των νοσοκομείων δεν έχουν διακομιστή και συχνά ούτε πρόσβαση στο
δίκτυο. Το `build.mjs` ενσωματώνει τη SheetJS, το CSS, τα λογότυπα και το πακέτο
της εφαρμογής μέσα στη σελίδα, και **αποτυγχάνει** αν το αποτέλεσμα ξεπεράσει τα
3 MB ή αν μείνει κάποια εξωτερική αναφορά. Σημερινό μέγεθος: ~0,98 MB.

Μοναδική εξαίρεση, κληρονομιά του v1.4: το `@import` της γραμματοσειράς Lato από
τα Google Fonts. Εκτός δικτύου η σελίδα πέφτει καθαρά στην Arial. Η αφαίρεσή του
ανήκει στο milestone 6 (έλεγχος πλήρους offline λειτουργίας)· μέχρι τότε το
`test/build.test.mjs` το «καρφώνει», ώστε να μην προστεθεί κατά λάθος δεύτερη.

## Ανά κλινική

Ο πίνακας του νοσοκομείου δεν απαντά στο ερώτημα του διευθυντή κλινικής: «πώς
πάει *η δική μου* κλινική;». Η ενότητα **«Ανά κλινική»** το κάνει.

Επιλέγετε κλινική (ή πατάτε τη γραμμή της στον πίνακα) και βλέπετε:

- **Δείκτες της κλινικής** — εισαγωγές, επισκέψεις εξωτερικών ιατρείων, ημερήσια
  νοσηλεία, χειρουργικές επεμβάσεις, πληρότητα κλινών, μέση διάρκεια νοσηλείας.
- **Μεταβολή έναντι του προηγούμενου έτους**, πάντα στην ίδια περίοδο
  (Ιαν–Μαρ έναντι Ιαν–Μαρ), ποτέ έτος έναντι τριμήνου.
- **Διαχρονική πορεία** — η ίδια περίοδος κάθε έτους που περιέχει το αρχείο, ως
  στήλες, με συνολική και μέση ετήσια μεταβολή.
- **Μηνιαία πορεία** των εισαγωγών και των εξωτερικών ιατρείων, με τα δύο
  προηγούμενα έτη από πίσω.
- **Έσοδα και τιμολόγηση ΟΑΥ** για την κλινική: τιμολογημένα €, περιστατικά DRG,
  έσοδο ανά περιστατικό, CMI, ΜΔΝ, επείγουσες εισαγωγές, αναθεωρήσεις.
- **Θέση στο νοσοκομείο** (π.χ. «1η από 6 σε εισαγωγές», «31,4% του νοσοκομείου»)
  και σύντομη αφήγηση στα ελληνικά, έτοιμη για αναφορά.

Από κάτω, ο συγκεντρωτικός πίνακας όλων των κλινικών με τιμή και Δ% ανά δείκτη.

### Πώς ενώνονται τα δεδομένα

Κάθε φύλλο γράφει την ίδια κλινική αλλιώς — «Παθολογική» στις εισαγωγές,
«Παθολογικά» στα εξωτερικά, «INTERNAL MEDICINE» στα αρχεία του ΟΑΥ. Η
`clinicKey()` (`src/domain.js`) αφαιρεί τις λέξεις-περιτύλιγμα (κλινική, ιατρεία,
μονάδα) και κόβει την κατάληξη του επιθέτου στο θέμα -ΙΚ-, ενώ οι αγγλικές
ειδικότητες περνούν από πίνακα αντιστοίχισης.

### Τι δεν λέει

- Τα **έσοδα ανά κλινική** προέρχονται από τη στήλη `Claim Speciality` των IS
  Auditor και είναι **τιμολογημένα προς τον ΟΑΥ, όχι εισπραγμένα**. Δεν
  περιλαμβάνουν ΤΑΕΠ και εξωτερικά ιατρεία: αυτά πληρώνονται συνολικά ανά
  νοσοκομείο (ALL and AE) και τα αρχεία του ΟΑΥ δεν τα επιμερίζουν ανά κλινική.
  Δεν επινοείται επιμερισμός.
- Ειδικότητες του ΟΑΥ που δεν αντιστοιχίζονται σε κλινική του αρχείου
  στατιστικών **εμφανίζονται ονομαστικά με το ποσό τους** κάτω από τον πίνακα.
  Κανένα ευρώ δεν εξαφανίζεται σιωπηλά — και η λίστα δείχνει αμέσως ποια
  ονομασία χρειάζεται αντιστοίχιση.
- Χωρίς αρχεία IS Auditor η ενότητα δουλεύει κανονικά με τους δείκτες του
  αρχείου στατιστικών· η καρτέλα εσόδων λέει ποια αρχεία λείπουν.

## Δοκιμές

| Αρχείο | Τι ελέγχει |
| --- | --- |
| `test/unit.test.mjs` | οι κανόνες πεδίου του brief, με συγκεκριμένους αριθμούς |
| `test/build.test.mjs` | ένα αρχείο, <3 MB, καμία εξωτερική αναφορά, καμία θέση του v1.4 δεν χάθηκε |
| `test/golden.test.mjs` | ό,τι έδειχνε το v1.4 μένει **ταυτόσημο**· η νέα ενότητα ελέγχεται χωριστά |

Το golden test φορτώνει και τις δύο σελίδες σε headless Chromium, περνά τα ίδια
αρχεία μέσω `setInputFiles` στο κρυφό input και συγκρίνει χαρακτήρα προς
χαρακτήρα. Συγκρίνονται οι περιοχές που είχε το v1.4 (`story`, `kpis`, `trends`,
`targets`, `flags`, `hio`, `allae`, `os`, `method`) και τα πεδία του `state` που
υπολόγιζε — όχι ολόκληρο το `<main>`, γιατί η εφαρμογή πλέον προσθέτει ενότητες.
Κάθε νέα ενότητα δηλώνεται ρητά στο `build.test.mjs`, ώστε να μη μπορεί να
εμφανιστεί κατά λάθος. Αν μια αλλαγή αλλάξει έστω ένα νούμερο του v1.4, το test
δείχνει την ακριβή θέση της διαφοράς.

### Τα δεδομένα δοκιμών

Τα πραγματικά αρχεία δεν μπορούν να μπουν στο αποθετήριο (περιέχουν ονόματα
ασθενών). Το `test/fixtures/make-fixtures.mjs` παράγει ντετερμινιστικά συνθετικά
βιβλία εργασίας που αναπαράγουν τη **δομή** και των τεσσάρων οικογενειών, σε
περίπου το ένα δέκατο του πραγματικού όγκου — οι αναλογίες βγαίνουν ίδιες
(κάλυψη ΤΑΕΠ 81%, εξωτερικά 83%).

Καλύπτονται και οι δύσκολες περιπτώσεις: μήνας υποβολής ≠ μήνας εξιτηρίου,
ΜΑΚΑΡΕΙΟ πριν από ΛΕΥΚΩΣΙΑΣ, ημερήσια νοσηλεία `3*`, αιμοκάθαρση ZF-041 με
άθροισμα `Quantity`, ανακτήσεις αναθεωρήσεων ανά `Case Nbr`, ετικέτα `-NGH-` και
` NGH-`, αποδιπλασιασμός ανά `CLAIM ID`, μηδενικά μελλοντικών μηνών, `#REF!` σε
στόχο και κείμενο σε αριθμητικό κελί. Για την ανάλυση ανά κλινική: η ίδια κλινική
με διαφορετική ονομασία σε κάθε φύλλο, αγγλικές ειδικότητες στο `Claim Speciality`
και μία ειδικότητα (NEPHROLOGY) χωρίς αντίστοιχη κλινική.

> **Τα νούμερα αποδοχής του brief** (Εισαγωγές 5.949, ΤΑΕΠ ενηλίκων 11.652,
> Ιαν ΤΑΕΠ 3.217/3.992 = 81%, F1054 285.620 € κ.λπ.) ελέγχονται μόνο με τα
> πραγματικά αρχεία Ιαν–Μαρ 2026. Δεν υπάρχουν σε αυτό το αποθετήριο, άρα δεν
> έχουν επιβεβαιωθεί εδώ. Ο έλεγχος ανήκει στο milestone 6 και γίνεται τοπικά:
> `npm run build`, άνοιγμα του `dist/…html`, φόρτωση των πραγματικών αρχείων.

### Playwright

Η έκδοση `playwright@1.56.0` είναι καρφωμένη γιατί ταιριάζει με το Chromium που
είναι προεγκατεστημένο σε αυτό το περιβάλλον. Σε καθαρό μηχάνημα ή σε CI:
`npx playwright install chromium`.

Το `setInputFiles` παίρνει **τα bytes**, όχι διαδρομές αρχείων: με ελληνικούς
χαρακτήρες στη διαδρομή ο Chromium δεν προσαρτά τίποτα, χωρίς σφάλμα, και το
test κολλάει. Τα ονόματα παραμένουν τα πραγματικά ελληνικά — ο parser των OS
διαβάζει τον κωδικό παρόχου (F1054) από το όνομα του αρχείου.
